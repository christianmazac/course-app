# Give feedback people can use

Useful feedback focuses on a specific behavior and its impact, then invites a next step. It is more helpful when offered with respect and room for the other person's perspective.

## Try this structure

- **Context:** When did this happen?
- **Observation:** What did you see or hear, without guessing intent?
- **Impact:** What effect did it have?
- **Invitation:** What could we try next time?

For example: “In today's handoff, the deadline was not included, so I wasn't sure what to prioritize. Could we add the due date to the next handoff?”

## Make it a conversation

Ask if it is a good time, listen to their response, and be open to new information. Feedback is not a verdict on someone's character; it is an opportunity to improve a shared situation.
