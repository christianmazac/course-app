# Build a tiny habit loop

A repeatable habit often has a cue, a very small action, and a satisfying sense of completion. The first version should be so manageable that you can practice it on a busy day.

## Write an if-then plan

“After I [existing routine], I will [tiny action] in [specific place].”

For example: “After I make tea, I will open my notebook and write one priority.” The cue connects the new action to a routine that already happens.

## Make it forgiving

Define a minimum version that still counts as practice. If you miss a day, restart at the next cue; you do not need to compensate or double the effort. Once the action feels familiar, decide whether to grow it.
