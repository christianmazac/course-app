# Make the helpful choice easier

Willpower is unreliable when a distracting option is one tap away and the work is vague. Design the environment so that beginning the task takes less effort.

## Prepare a focus session

1. Write one visible next action, such as “draft the opening paragraph.”
2. Put the materials you need within reach.
3. Move one likely distraction farther away or silence it.
4. Choose a gentle time box, such as 15 minutes, then decide whether to continue.

Keep the session small enough to start. A break is part of a sustainable rhythm, not a reward you have to earn.

## If you get interrupted

Note the interruption, return to the written next action, and restart with a shorter time box if needed. Each return is practice.
