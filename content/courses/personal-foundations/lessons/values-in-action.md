# Turn values into everyday choices

Values are directions, not finish lines. “Connection” or “craft” becomes useful when it helps you choose what to do in a real situation.

## Try it

Pick one value that matters to you. Complete these sentences:

1. “This value matters because…”
2. “When I live it in a small way, someone could see me…”
3. “One situation where I can practice it this week is…”

Make the action small enough that you can do it on an ordinary day. If your value is learning, you might ask one sincere question. If it is care, you might give someone your full attention for five minutes.

## Reflect

Values can compete. When that happens, name both values and choose a reasonable next step rather than expecting a perfect answer.
